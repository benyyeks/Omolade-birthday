# Happy Birthday Elizabeth Omolade Yekinni

Private birthday website for my biggest sis.

## How to use

1. Open `index.html` (the PIN login page).
2. Default PIN is **2208** (change it in the script if you want).
3. After correct PIN it redirects to `birthday.html`.

## Deploy on Netlify

1. Push this folder to a GitHub repository.
2. In Netlify: New site from Git → select the repo.
3. Deploy settings can stay default (no build command needed – pure HTML).

## Structure

- `index.html` – PIN locker with ink splash background
- `birthday.html` – Main celebration page (hero, fireworks, photo timeline, interactive envelope letter)
- `images/` – The 10 selected photos

## Notes

- Soft Paper & Ink aesthetic
- Responsive
- Fireworks launch from the bottom
- Envelope has two-stage open (tip peek → full letter)
